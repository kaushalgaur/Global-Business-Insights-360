# Global Business Insights 360

## Project Overview
**Global Business Insights 360** helps businesses gain quick insights across multiple markets and make data-driven decisions.

**Motto:** "Start the day with analysis"  
**Target Audience:** Executives, Finance, Supply Chain, Sales, Marketing teams  
**Timeline:** Started in Q2 FY 2022

## Objectives
- Promote data-driven decision making  
- Unlock actionable insights from business data  
- Reduce manual work  
- Ensure data transparency  

## Key Features / Dashboard Views
1. **Finance View:** Profit & Loss statements, market/product/customer performance  
2. **Sales View:** Top & bottom customers, key metrics, matrix view  
3. **Marketing View:** Product performance metrics  
4. **Supply Chain View:** Reliability & Forecast Accuracy  
5. **Executive View:** Integrated key insights for executives  

## Success Measures
- Functional dashboard with key business metrics  
- Tool usage in business review meetings, negotiations, product launches, marketing promotions, budgeting  
- Improve communication & decision-making .  

## How to Use
1. Open the `.pbix` file in Power BI Desktop  
2. Explore interactive visuals for each view  
3. Optional: Use screenshots from `Visuals/` folder if PBIX is unavailable
